# Blaze’s Beasts

Play: https://realamarablaze.github.io/blazes-beasts/

Original browser-based creature fighting prototype **0.2.4**. Pick three of six beasts,
create a cosmetic avatar and challenge a ten-stage campaign, the computer, or a friend
on the same keyboard. Friendly arcade competition, original chunky pixel creatures,
and synthesized game sounds. No accounts, purchases or paid services required.

## Controls

- Player 1: **A/D** move, **W** jump, **S** guard, **F** light, **G** heavy, **H** Spark.
- Player 2: **Left/Right** move, **Up** jump, **Down** guard, **J/K/L** attacks.
- **P/Escape** pause, **M** mute. Touch buttons control player 1.
- First to two rounds wins. Campaign stages allow three match attempts; a stage win
  earns a heart piece. Connect light → heavy → Spark for an optional timed combo.

Audio requires a user gesture. Saves and scores stay in this browser/device; use
Export/Import to move them. Local file/localhost saves do not automatically transfer
to this HTTPS site. Leaving/reloading a campaign match spends the reserved attempt.

Prototype: balance, physical-device touch, audible output and human victory/reward
playthroughs still need testing. System reduced-motion preference is supported.
No network multiplayer or global leaderboard. Optional artist links open externally.

This public repository contains only the static runtime and this player guide.
The artwork is drawn in JavaScript; no reference photographs, comparison images,
personal saved profiles, developer notes or credentials are included. Source code
and browser assets are publicly viewable.
